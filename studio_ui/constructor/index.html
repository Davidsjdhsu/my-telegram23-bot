Сохранено на этом устройстве

Черновик откроется автоматически, когда вы снова зайдёте в конструктор на этом устройстве. На другом устройстве его не будет. Очистка данных браузера может удалить черновик.

Для переноса выберите «Скачать копию проекта». Чтобы получить PPTX в чате, нажмите «Получить презентацию».

Выберите схему

Добавится на новый слайд. Текущий слайд сохранится.

Открыть редактируемую копию?

    Текущий черновик будет заменён. После открытия можно нажать «Отменить», чтобы вернуть его. За открытие файла кредиты не списываются.
