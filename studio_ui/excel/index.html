Настроить расчёт

Выберите готовый вариант или укажите, какие величины складывать, вычитать, умножать или делить. Расчёт заменит столбец результата во всех строках.

Результат будет числом без знака ₽. Выбирайте величины, которые имеет смысл считать вместе. Итог — сумма результатов всех строк.

Настраивается один раз. Все позиции сохранятся. Проценты и заданные числа можно будет менять на листе «Расчёт» в Excel.
